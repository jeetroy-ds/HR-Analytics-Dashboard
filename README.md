# HR Analytics Dashboard

An interactive **HR Analytics Dashboard** developed using Power BI to analyze employee data, workforce trends, attrition, compensation, and other key human-resource metrics.

The dashboard helps HR teams and business stakeholders monitor workforce performance and identify important patterns through interactive visualizations and KPIs.

##  Project Objective

The objective of this project is to transform raw HR data into meaningful insights that can help organizations understand:

- Employee workforce composition
- Employee attrition
- Department-wise workforce trends
- Salary and compensation patterns
- Employee demographics
- Job satisfaction and performance
- Workforce distribution and trends
